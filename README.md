# DevKit Space

Developer tools for people who build things.

## Setup

```bash
bun install
```

## Development

```bash
bun run dev
```

## Tests

```bash
bun run test
bunx playwright install chromium
bun run test:e2e
```

## Production

```bash
bun run build
bun run preview
```
