# Code of Conduct

This project is open to all people. This page tells you how to act in the project spaces. The
project spaces are the issues, the pull requests, the discussions, and the reviews.

## Do

- Be kind and respectful to other people.
- Accept different opinions and experience.
- Give feedback about the work, not about the person.
- Accept feedback and learn from your errors.

## Do not

- Do not use sexual language or images.
- Do not insult, attack, or troll other people.
- Do not harass other people in public or in private.
- Do not publish private data of other people without their permission.
- Do not do other things that a reasonable person thinks are not correct in a work space.

## Report a problem

To report behavior that does not obey this code, send a message to the maintainer,
[@hamedniroomand](https://github.com/hamedniroomand) on GitHub. The maintainer keeps the report
private.

## Result

The maintainer can remove comments, commits, issues, and pull requests that do not obey this code.
The maintainer can block a person from the project for a time or for all time.

This code is based on the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
